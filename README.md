# Análisis de Interfaces · Horno de microondas

**Unidad 1 · Interfaces Sonoras · Entrega 1** · Taller de Diseño de Interfaces, Universidad Adolfo Ibáñez · 2026 · Prof. Jorge Forero
Autor: Luis-Felipe Benitez · Ficha: https://portafolio.insta3d.cl/analisis-interfaces/

## Objetivos
- Identificar las interfaces de entrada y salida de un objeto cotidiano: un horno de microondas.
- Clasificarlas según su tipología: **física** (mecánica o táctil), **visual** (luz o pantalla) y **acústica** (sonido).
- Explicar cómo funciona cada una en una lámina clara e interactiva.

## Descripción
El microondas se usa todos los días sin pensar en cómo «conversa» con nosotros: botones que se aprietan, una pantalla que cuenta, un pitido que avisa. La lámina separa esas capas para mostrar que un mismo objeto combina varias interfaces, y que el sonido cumple una función clave (confirmar, avisar, terminar).
**Público y contexto:** compañeros y profesores del taller; sirve como herramienta de análisis para cualquier objeto doméstico.

## Tecnologías
- Diagrama vectorial propio (SVG) y versión PNG de alta resolución (3200 × 2300).
- Lámina interactiva en HTML, CSS y JavaScript: se filtra por tipología y cada interfaz se resalta al seleccionarla.

## Cómo verla
Abre `index.html` en cualquier navegador; no necesita instalación. También: `lamina-microondas.svg` (vectorial) y `lamina-microondas.png`.

## Proceso
1. Observación y registro del microondas real: cada control, luz y sonido.
2. Clasificación en tabla: entrada o salida y tipología.
3. Diagrama vectorial con numeración de cada interfaz.
4. Versión interactiva con filtros por tipología.

> 📌 **Por aportar:** fotos del microondas analizado, el boceto inicial de la lámina y la tabla de clasificación a mano (carpeta `proceso/`).
